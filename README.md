# Data Structures & Algorithms (数据结构与算法经典实战)

> ⚡ **经典数据结构与算法实战项目集**，涵盖线性表、栈与队列、二叉树与堆、散列表、图论与高级排序算法。全库代码采用**标准纯英文命名**，配备**教学级注释与开箱即用运行示例**。

---

## ⚡ 极速开始 (编译与运行)

本项目源码均为独立自包含的单文件，无需构建工具即可一键编译运行：

```bash
# 1. 编译并运行任意单文件算法（以快速排序为例）
gcc -Wall -Wextra c/14_advanced_sorting_algorithms/01_quick_sort.c -o app && ./app

# 2. 一次性语法检查所有 C 源码
gcc -Wall -Wextra -fsyntax-only c/*/*.c
```
